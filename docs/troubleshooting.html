Testing Failures

  • No continuity: Check probe contact, oxide removal
  • Won't boot: Verify power supply, check programming
  • Low yield: Review all process parameters
  • Random failures: ESD damage, improve grounding

Equipment Issues

  • Furnace won't heat: Check heating elements, controller
  • Spin coater uneven: Level platform, clean chuck
  • UV lamp dim: Replace bulb (500hr lifetime)
  • Hood not venting: Check fan, filters, ductwork

When to Ask for Help

  • Persistent yield below 40%
  • Chemical safety concerns
  • Equipment malfunctions
  • Process completely failing
