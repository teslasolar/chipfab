🏗️ Infrastructure

  • Fume Hood: $2K - MANDATORY for HF/acids
  • Fire Suppression: Class D extinguisher
  • Ventilation: HVAC exhaust system
  • Zoning: Light industrial approval

🧤 Personal Protection

  • Chemical gloves (nitrile + neoprene)
  • Face shield + safety goggles
  • Chemical apron
  • Closed-toe shoes

🧪 Chemical Hazards

  • HF (Hydrofluoric Acid): Ca-gluconate gel required
  • POCl3/BBr3: Toxic gas - sealed system
  • Solvents: Acetone, IPA - flammable
  • Storage: Segregated, labeled, MSDS on file

📋 Compliance

  • EPA: Hazmat waste disposal license
  • OSHA: Worker safety training
  • Insurance: $2K/year for $1M liability
  • Inspection: Annual safety audit

🚨 Emergency

  • Emergency shower + eyewash station
  • First aid kit with Ca-gluconate
  • Emergency contacts posted
  • Spill kit accessible
